## 整周有序，今天清楚。

![网格课表、周视图与今日课程的真实手机界面。](readme/media/v0.1.1/week-and-today.jpg)

**网格看全貌，周视图按天浏览，今日页专注当天。** 课表名、周次和更多操作集中在简洁的顶部；点击课程查看详情，需要时再编辑。

上完的课程会淡化，方便分辨已上和未上。普通周末有课仍正常显示；节假日与补课安排可以按实际情况设置。灰显只是显示提示，不等于取消课程或关闭提醒。

## 把整个学期，看得更清楚。

一门课持续几周，是单双周，还是只在前半学期上？**学期安排**用周次分布回答这些问题。点开课程，再用月历查看具体日期，以及当天的时间和教室。

![学期安排的课程周次分布与上课日历。](readme/media/v0.1.1/semester.jpg)

入口：**课表右上角「更多」→ 学期安排**。

## 不用打开 App，也能心中有数。

四种桌面小组件，从眼前这一节到整周安排，选择适合自己的信息密度。

![vivo 手机真实桌面上的今日小组件、今日列表、两日课程和本周网格。](readme/media/v0.1.1/widgets.jpg)

| 小组件 | 适合怎样查看 |
| --- | --- |
| **今日·小** | 留出一小块桌面，随手看当天课程 |
| **今日** | 横向列表，查看课程、时间和地点 |
| **两日** | 今天与明天并排，提前安排第二天 |
| **本周** | 网格呈现一周分布，可滚动查看后续节次 |

小组件可以指定课表、隐藏课表名称；本周网格支持色条与填充，课程名位置可独立选择。实际尺寸和可见内容随桌面网格变化。部分桌面需要长按空白处，手动添加 Classy 小组件。

## 你的课表，你的颜色。

**浅色清爽，深色沉静。** 课程可以用柔和填充区分，也可以只保留一条简洁的色标。课名靠上或居中，由你选择。

![浅色色条、深色色条与深色填充的真实课表对照。](readme/media/v0.1.1/appearance.jpg)

主题可跟随系统壁纸取色（Android 12+），也可选择内置配色或创建自己的主题。

## 换一张背景，也换一种心情。

选择喜欢的图片，调整浓淡、模糊、色彩浓度与裁切位置。背景保留气氛，课程依然是画面的主角。

![在 App 中实际设置的晨光与极光渐变背景，分别搭配浅色与深色色条课表。](readme/media/v0.1.1/background.jpg)

入口：**我的 → 外观与主题 → 课表背景**。展示使用原创渐变图片；这是真实自定义背景效果，不是液态玻璃。

## 日常操作，也值得认真设计。

| 想做的事 | Classy 可以帮你 |
| --- | --- |
| 导入已有课表 | 从支持的教务系统、文件或文本导入，先预览再确认 |
| 获取最新安排 | 从教务更新当前课表，保留作息，提交前核对变化与本地修改 |
| 调整上课时间 | 编辑课程、临时调课，或单独管理可复用的作息表 |
| 提前做好准备 | 设置课前提醒与每日摘要；送达与展示仍受系统权限和省电影响 |
| 留存与迁移 | 导出课表和作息，便于备份、分享或换设备 |

## 时间属于你，数据也是。

- **免费、开源、无广告，不接入广告或统计 SDK。**
- **课表保存在本地，日常查看离线可用。** 教务导入、节假日数据、更新检查等功能会联网。
- **教务登录后在设备上解析课程，不经 Classy 中转服务器。** 学校兼容情况以实际教务系统为准。
- **支持导入与导出。** Classy、ICS、CSV、WakeUp 文本 / JSON、HTML 等入口与限制见 [使用指南](readme/GUIDE.zh-CN.md#导入与导出)。

## 把课表装进口袋，把时间留给生活。

[**免费下载 Android 版 ↗**](https://github.com/IMSX3D/Classy/releases/latest)

Android 8.0 及以上。大多数手机和平板选择 **app-arm64-v8a-release.apk**；其他架构见 Release。

已有同签名正式版可覆盖安装，升级前建议导出课表备份。测试版与正式版是独立应用，需要通过导出、导入迁移数据。应用内可到 **我的 → 关于 → 获取更新** 下载新版并交给系统确认安装。
