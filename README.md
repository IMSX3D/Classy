## 整周有序，今天清楚。

周一到周日，先看全貌；出门之前，只看今天。

Classy 提供网格、周视图与今日三种视图。课程、时间、地点，在不同的查看方式里各就其位。你可以浏览整周，也可以把注意力留给眼前这一节。

## 抬眼之间，心里有数。

下一节在哪，今天还有几节课，不必每次都打开 App。

把「今日课程」「最近两天」或「本周课表」放到桌面。小组件跟随 App 主题，让课程安排成为日常里轻轻一瞥就能看清的事。

## 你的课表，你的颜色。

浅色清爽，深色沉静。主题可以跟随系统，也可以从内置配色出发，调成你喜欢的样子。

课程色既可以铺满卡片，也可以收成一条细细的色标。醒目一点，或安静一点，由你决定。

## 时间属于你，数据也是。

**没有广告，不接入广告或统计 SDK。** 查看课表，不用先看完别的东西。

**本地保存，日常离线可用。** 课表保存在设备上；教务导入、节假日数据与更新检查等功能会联网。自动检查更新可在「关于」页关闭。

**导得进，也带得走。** 支持教务系统导入，以及 Classy、ICS、CSV、WakeUp 分享文本 / JSON、HTML 表格等导入方式；导入先预览，再确认。也可将课表导出，继续在支持相应格式的工具中使用。

教务导入在登录学校系统后本地解析，不经 Classy 中转服务器。学校适配情况以实际教务系统为准。[查看导入与导出说明 →](readme/GUIDE.zh-CN.md#导入与导出)
