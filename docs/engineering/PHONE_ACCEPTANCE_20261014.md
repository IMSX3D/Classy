# 手机端验收：保持平板稳定基线

> 历史记录：本文写于 2026-10-14，记录当时的验收过程。"本机证据目录""交付目录"是开发者本机路径，不随仓库分发；结论与判据仍有效。

用户目标：手机应达到已认可的平板简洁、美观、组件与流畅体验。平板优化提交 `4b318c2` 不做无目标微调；共用首帧与 Preview 构建优化直接沿用。

## 具体验收

| 范围 | 检查 | 通过依据 |
| --- | --- | --- |
| 冷启动 | 当前周一次完整出现，无加载中闪过、假空态、随后滚动定位；带现有组件绑定测三次 | 真手机 Preview 的录屏和独立启动计时，不以模拟器代替 |
| 首次入口 | 我的→小组件、返回、二次进入；数据就绪不挪动布局 | 同手机、同数据、同构建采样；残余长帧有界处理 |
| 紧凑布局 | 顶部名称/周次/更多，课名/教师/教室，底部导航、弹层与键盘 | 360dp级窄屏及常见手机尺寸，正常字号与1.5倍字号；不将平板缩小当作验收 |
| 桌面组件 | 当前已有实例、名称隐藏、圆角、刷新与宿主网格匹配 | 真手机桌面实显；用户手动添加不计自动添加成功 |
| 操作闭环 | 课表→课程详情→编辑→取消/保存返回；学期课程→月历→返回 | 草稿/选中周/滚动位置不丢失；不为测试改动真实课程 |

开始时只连接 vivo 平板与 Android 15 模拟器；已向用户请求连接手机。模拟器现有窗口为540×960px、density240，即360×640dp，字体1.5，仅用于阅读和状态行为补验。手机具体品牌、系统与性能结论等待实际设备，不能猜测。

手机验证仍采用有界原则：先复现、定位再修复；没有具体缺陷不新建视觉体系，保持手机和平板共用组件与一致语义。原子岛、跨品牌自动添加、全仓逐行重整不因这一轮自动恢复。

## 本轮实际结果

随后连接 vivo V2507A / Android 16，1080×2400px、density480（360dp宽），原版本0.0.9-debug。覆盖安装 `0.1.0-preview`（与平板相同APK），已看到升级说明并关闭，保留原课表和四个已绑定组件。旧包不是相同源码，不据此计算代码优化提升百分比。

三次强制停止后冷启动，系统 `Displayed` 与 `Fully drawn` 分别同时为 **191 / 192 / 197ms**。当前周课程从首个应用画面一起显示，独立录屏未见中间加载文字或逐批课程；系统桌面启动动画仍正常存在，不计作零延迟承诺。

首次小组件进出链 P95 **26 / 21 / 23ms**，P99 **44 / 48 / 48ms**。仍有个别长帧，不宣称120Hz每帧均达标。测量条件正常字号1.0、既有真实数据和四个组件绑定，不录屏；录像另采。证据目录 `本机证据目录/phone-final/`，脚本校准点 `--mine 810 2260 --widgets 550 1032`。

已补验深/浅色课表、我的→组件→返回、正常及1.5倍字号组件设置，文字与开关未见重叠。测试后恢复用户原深色和系统字号1.0。没有为满足七列密度而缩小用户字号：360dp且1.5倍字号时，课程名称与地点省略明显，完整阅读仍需课程详情/其他现有视图，此限制保留，不能称为大字号七列阅读完美。

模拟器360×640dp、1.5字号下课程阅读与学期课程详情三项测试通过（`final-phone-narrow-tests.txt`），包括日期/真实时间和选择恢复；不代替手机性能。手机本轮不测试真实课程保存改动，不在线重新导入、不改作息与提醒配置。桌面自动添加、通知长期可靠性仍按原边界暂缓。

真实手机补验课程详情→编辑目标时段→系统返回，未输入或保存任何课程变更，返回课表成功；桌面当前页网格与今日组件恢复实际课程内容。已绑定四个实例的系统列表存在，不宣称四个实例所有缩放规格均验收。最终停留课表页，深色与字号1.0已恢复，用户可继续体验。

平板基线与本轮手机共用同一APK，没有为了手机另改平板样式。全机型保证、七列大字无省略、普通通知重启/长期省电仍不包含在当前通过范围。当前手机普通字号和关键操作样本已验收，停止没有明确问题的微调。
