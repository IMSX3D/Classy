## 实现边界

- `AppPrefs` getter 是首次安装与恢复默认的共同来源；`resetSettings` 清除设置后直接使用它们，不引入第二套重置值。
- 保留现有已保存的个人选择；更新安装不会强行覆盖用户配置。提醒总开关关闭时，开启的子选项不自动发送通知，系统通知权限也不是应用默认偏好。
- 账户、教务凭据、课程、作息、每张课表的调休数据、小组件绑定及日期导航不是出厂设置。不得复制设备整份偏好文件到仓库；原始捕获仅在仓库外保存。
- 不扩大已有“恢复默认设置”的数据清理范围；课表数据库、自定义主题及调休映射保持原有保护。
- 新默认采用本次实际手机的填充模式；早期设计稿选择色条不覆盖当前明确的设备配置要求。
