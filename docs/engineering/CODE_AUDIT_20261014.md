### 仍有维护债务及验收边界

- lint 当前 app 590 warnings / 22 hints，库 13 warnings，无 errors。主要为未用资源、KTX 建议、旧排版及控件描述；“不报错”不代表没有债务。未用资源中含历史组件/预览兼容路径，未批量删除；用户要求保留上游吸收能力。
- 学校匹配的注册域启发式只用于目录候选，不能再复用作证书信任判断。无效证书的学校页面现在会被阻止，应修复学校证书或通过系统明确安装可信 CA，不能恢复自动绕过。
- 现有 HTTP 学校、用户安装 CA、诊断导出、Debug 测试入口有明确兼容/调试用途；未扩大网络权限，也未自动导出或上传用户数据。诊断包可包含个人课程/网络会话，应留在用户主动导出流程。
- 本轮没有逐个重写全部 327 文件，没有对每家学校在线登录。复杂长文件拆分与全量人工注释复核仍是后续维护工作；不以目录清单、全绿测试或本报告冒充已完成。
- 全部厂商组合、生产更新下载到安装、TalkBack 实际语音、原子岛资格、连续多日省电可靠性无法由本轮现有设备全部证明，见收口记录。
