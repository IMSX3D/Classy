## 入口决策和修复

| ID | 原问题 | 决策与实现 |
| --- | --- | --- |
| COURSE-COLOR-04 | 组色确认先关窗再写入；失败无反馈；重复操作与旋转中断没有保护 | 两段选择保留；确认框在成功后关闭，忙时禁用确认/取消/返回，失败原框重试。每个编辑会话的ViewModel持有操作，不因配置重建取消写入；结果只消费一次。待确认色使用保存状态 |

| COURSE-COLOR-06 | 新建课程显示改组色，但无editingCourse导致实际无操作 | 新建模式只改草稿，确认文案明确随创建生效；纳入未保存检测，创建时只写GROUP行 |
| DIALOG-SHORT-02 | 短横屏English1.5下，组色错误提示增加后，重试按钮不可用 | 删除和组色确认将操作放到固定按钮区，说明/错误正文可滚动；按钮区域不随正文长度被挤走 |
| COURSE-COPY-04 | 基础信息区提示先填教师/地点，但该区只有名称/别名 | 中英文改为先填课程名称、再设时段，与真实流程一致 |
