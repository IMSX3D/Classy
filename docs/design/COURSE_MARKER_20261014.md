# 课程色条与圆角修正

2026-10-14，用户授权。

原因：网格卡约12dp圆角与3dp内边距不协调，色条几乎满高；默认浅色卡面与底板同白色隐藏了轮廓问题，深色不同表面层级暴露问题。

实现：普通网格色条左侧总内缩6dp，上下由圆角×0.65与6dp基准共同决定，并限制到卡片高度的四分之一，文本独立保留空间。色条保持3dp圆头，不作为边框。底色在卡面与底板语义色间混合55%，保持不透明背景，降低深色嵌套反差；不更改保存的课色或填充模式。原按压反馈仍受卡片圆角裁切。

核查：周列表已有8/9dp留白，保留。冲突卡为独立填充层叠，保留用于分层的轮廓，没有新增色条。原生桌面周网格调整色条左4dp、上下7dp并同步文字左侧预留9dp；旧Canvas网格也改内缩。组件圆角drawable误导性的逐节拼接注释已纠正。

验证：Debug/AndroidTest构建成功，CourseReadingTest共2项通过（既有填充文字测试及新增色条短/长卡明暗样板）。查看marker-dark.png、marker-light.png及实际平板深色课表截图marker-pad-bar.png，保存在E:/C015/99-整理记录，不提交真实课表截图。平板覆盖安装成功；测试时临时切换色条，检查后恢复设备原填充偏好。课程与组件绑定未清除。
