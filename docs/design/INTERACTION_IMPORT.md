# 第三轮：导入操作与组件选择

> 历史记录：本文写于 当时，记录当时的验收过程。"本机证据目录""交付目录"是开发者本机路径，不随仓库分发；结论与判据仍有效。

执行范围：教务导入与文件/文本导入的最终核对步骤、作息配置、提交失败与返回。

| 入口 | 组件选择 | 行为契约 |
| --- | --- | --- |
| 核对名称、日期与作息 | 全屏任务页，内容最大宽 720dp | 表单可滚动，操作位于底部，键盘与系统边距统一处理；只有确认导入写库 |
| 作息摘要 | 导航行 | 展示来源与节数，点击进入全屏作息配置，避免确认页堆叠所有时间输入 |
| 作息选择与逐节/自动编辑 | 独立全屏配置步骤 | 在局部草稿上操作，点完成才回传；返回有修改则询问，取消保留局部输入 |
| 日期 | 现有日期选择器 | 一个字段的小任务，无需新页面 |
| 文件核对返回 | 回预览前确认放弃本步修改 | 确认表单仍保留至退出选择；失败留在核对步骤可重试 |
| 教务核对返回 | 沿用继续/留草稿/丢弃退出确认 | 保留现有导入草稿机制，不再另造退出体系 |
| 提交 | 单个显式操作锁 | 提交中禁用重复操作和返回；失败在当前步骤提示，保留输入 |

教务确认直接使用 Activity 的整页内容；文件确认因入口仍由底部面板持有会话，使用全屏任务窗口承载，视觉布局与教务共用。此轮不重构全部导航宿主，不把底层预览和来源面板当成用户需要逐层关闭的界面。

先落地以上组件与数据时机，再进行独立的导航动效统一。设备验收覆盖手机、平板与分屏、键盘、1.5 倍字号；没有连接设备时只记录工程验证，不宣称实际观感已验收。

## 已实现与保留边界

- 教务与文件核对共用 ImportReviewPage；作息摘要复用既有卡片/箭头，配置复用 TimeSlotEditor，全屏选择列表随页面滚动。
- 作息编辑使用可恢复局部草稿；完成后回传，未完成返回通过公共放弃确认。切换到手动/自动时解除“使用已有作息”的选择，避免看似改了时间却保存旧作息；新建导入作息的选择保留。
- 教务导入复用 EditorActionState 防止重复提交，失败留在当前页；已有作息绑定与建课表在同一事务完成。成功后的草稿清理失败不会提示重新导入。
- 教务草稿序列化新增作息来源，兼容旧草稿默认新建的行为；明确区分 null、-1 和已有 ID。
- 文件确认提交中禁止修改/返回，失败留在确认步骤；返回预览前检查未保存修改。

本轮只迁移最终核对及作息配置；文件来源选择、课程预览和纯作息文件导入仍沿用既有容器。文件导入整段会话仍有原有的 Activity 重建/进程恢复限制，不宣称本轮已解决所有导入草稿恢复。教务 Activity 原有 orientation/screenSize 处理保留；跨进程恢复沿用持久化草稿。最终页面转场与连续手势将在动效轮统一并经设备验证。
