# 平板与可变窗口适配

日期：2026-10-11。用户新增正式需求：确保平板上正常显示、排版和使用。本文件为调研与实施方案，尚未完成平板改造或设备验收。

## 当前基础与缺口

- `SleepyNavHost.kt` 已使用 WindowSizeClass：非 Compact 窗口使用 NavigationRail，Compact 保留底栏/Dock。应在现有入口收敛，避免另建平板导航系统。
- `CourseTableView.kt` 已使用 BoxWithConstraints 和课表视口策略计算尺寸；纵向自适应与用户缩放已有独立规则。容器自适应不等于所有内容已适配大屏。
- 已有 Material3 adaptive / adaptive-layout 依赖。新导航或多栏 API 的可用性仍需按当前锁定依赖核对；不为复制最新样例直接升级全套依赖。
- 尚未验证：宽屏页面最大宽度、双栏状态与返回、旋转及窗口缩放后草稿/选中项保持、键盘和独立教务 Activity 的行为、鼠标/键盘操作。

## 布局原则

依据**当前可用窗口和内容区尺寸**选择布局，不能只判断设备型号或“是否平板”。平板分屏可能需要手机布局，手机横屏也可能需要侧边导航。宽度、可用高度、字体缩放和遮挡一起决定空间是否足够。

宽度分类以现有常见断点为初始候选：小于 600dp 为紧凑，600–839dp 为中等，840dp 起为展开；这些不是所有页面自动开启双栏的保证。扣除导航、安全区、栏间距后，两栏各自达到内容最小宽度才开启；课表按显示天数与可读列宽计算。低高度或大字体可继续使用单栏。

| 页面 | 紧凑窗口 | 较宽窗口 |
| --- | --- | --- |
| 课表 | 现有网格/周列表、底部导航 | 侧边导航，课表使用主要宽度；详情侧栏仅在扣除侧栏后课程列仍可读时开启，否则沿用详情页/弹层 |
| 今日 | 单列课程卡 | 内容限制合理阅读宽度，避免时间与课名被拉远；只有存在真实相关内容时才增加辅助栏 |
| 课表管理/课程列表 | 列表进入详情 | 优先试点列表＋详情，保持选中项；未选择时使用明确空态 |
| 设置与我的 | 分组列表进入子页 | 先保证限宽和一致对齐；设置类别＋设置内容双栏作为后续增强，复用同一份页面状态 |
| 新增/编辑/导入确认 | 适应键盘的表单或弹层 | 限宽表单，按钮可达，必要时正文滚动；不把输入框横向拉满整屏，也不把所有底部弹层机械改为侧栏 |
| 教务登录与导入 Activity | 现有 WebView 流程 | 检查窗口、缩放、旋转、弹窗和草稿恢复；不能因 Compose 主页面通过就认为独立 Activity 也通过 |

双栏是同一套数据与导航的不同呈现。收窄时保留当前课程/课表、周次、编辑草稿与滚动位置；展开时恢复关联列表。返回优先关闭当前覆盖层或返回所属列表，不能因布局变化多插入一份详情历史。

拖动课程时窗口改变，应保持正确坐标转换，或明确取消本次未提交拖动；不能误保存到另一日期/节次。窗口调整本身不触发保存、导入或删除。

## 两级实施范围

### 必须完成：可靠显示与操作

导航随窗口变化；所有页面合理限宽；横竖屏和分屏无截断/遮挡；编辑草稿、周次、选中课表和滚动状态可恢复；系统栏/键盘安全区正确；触摸命中与文字缩放正常。验证键盘 Tab 焦点、Enter/Space 激活、鼠标点击和滚轮，不要求新增复杂快捷键。

### 在基础稳定后增强：利用大屏空间

先做管理/课程列表＋详情的双栏样板，再评估课表详情侧栏与设置双栏。样板通过跨断点、返回、草稿状态验证后推广。折叠屏铰链避让列为扩展验证，不把其支持等同于普通平板基础验收。

## 验收矩阵

- 窗口：手机窄屏回归；平板竖屏、横屏；至少两档分屏比例；窗口连续拖动跨 600/840dp 边界；用 dp 记录，不能只记物理像素。模拟器覆盖布局边界，至少一台真实 Android 平板验证实际操作。
- 主题/文字：明暗主题、中文/English、1.0/1.3/1.5 倍字体、长课程名/地点、色条与填充模式。
- 状态：查看课程时旋转/分屏；输入未保存时旋转；已打开弹层时改变窗口；返回与预测性返回；进后台及进程重建后的合理恢复。自动恢复不能引起重复保存或提交。
- 课表：七天/工作日等已有显示选项、冲突课程、行高设置、拖动/撤销、点击位置准确；不能为了全屏塞下课表无限缩小字体。
- 输入：软件键盘出现/消失、硬件键盘、鼠标；保存和取消始终可达，焦点顺序有意义。
- 性能：大屏可见内容更多，单独记录滚动/拖动/切周帧表现；验证展开/收窄期间没有反复重建导致的明显卡顿。

验收记录区分“模拟器布局通过”“真机操作通过”“待覆盖设备”。未完成真机验证时不宣称已保证全部平板兼容。

## 与主计划的关系

P0 加入手机/平板基线；P1 的主题与样板从一开始覆盖可变窗口；P2 先完成所有页面的平板基础适配，再交付一个双栏样板；P3 增加多栏返回及布局变化动效检查；P5 把真实平板验收列为交付条件。玻璃优先级低于平板基础适配；首轮 Dock 玻璃不自动扩展到 NavigationRail。

## 2026-10-12 导航与桌面尺寸落地

宽屏 MainRoute 已改为左下方圆角导航区，背景与页面外层统一，保留消费 safeDrawing；取消整条异色侧栏。窗口不足时导航内容可滚动；Compact 仍为原底栏/Dock。不能把本轮横竖屏和短窗口验收视为全部分屏矩阵通过。

用户确认桌面组件的几×几表示网格数量，不要求几何正方形。四种卡片按实际宿主可用宽高铺满，保留系统格间距与组件内部16dp留白，不用推算像素边长替代宿主测量。OEM拥有格子尺寸和最小跨度；声明targetCellWidth/Height不能强制任意桌面按同样像素分配。
