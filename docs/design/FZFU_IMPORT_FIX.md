# 福州外语外贸学院：导入遗漏作息修复

> 历史记录：本文写于 2026-10-11，记录当时的验收过程。"本机证据目录""交付目录"是开发者本机路径，不随仓库分发；结论与判据仍有效。

日期：2026-10-11。

## 实际原因

使用用户授权的测试账号进行只读核对。当前学期为 2026 学年第一学期（xnm=2026、xqm=3），课表接口返回 23 条原始课程记录，校区标识为 1。学校公共课表脚本通过 `/kbcx/xskbcx_cxRjc.html` 读取每节上下课时间，字段为 `jcmc`、`qssj`、`jssj`，返回完整 11 节作息：第一节 08:25–09:10，最后一节 20:10–20:55。

Classy 原正方采集器只识别当前网页中特定格式的节次表头，没有读取该作息接口。结果是课程成功解析、节次时间缺失，并非只能导入 12 节。导入确认页默认选中的 -1 选项是“本次导入新建作息表”，先前外观与已有同名作息表相同，进一步造成误解。

## 修改

- 正方新版采集器按本次选定学期及课程中的唯一校区请求真实作息，不绑定特定学校或写死 11 节。
- 严格识别单节编号和有效时间；同一节出现矛盾时间时不取猜测值。缺校区或跨多个校区不擅选校区。作息接口请求最多等待 8 秒，失败保留课程及原表头回退路径。
- 有有效接口数据时不混入可能来自旧学期的页面表头。
- 确认页保留学校提供的完整作息，不按学生最后一门课截断；课程超出已知作息范围时仍提示补填缺失时间。
- 新建作息选项标注“本次导入新建”；选择已有作息后，不再用原始导入的空时间触发缺失提示；更换作息或编辑时间会清除过期错误。
- 缺失提示明确支持逐节填写、自动安排和已有作息三种方式。

不改已导入的用户课表，不自动替换用户自定义时间。旧的缺失时间草稿需要重新从教务读取，或选择已保存且完整的作息表。

## 验证

使用修改后的实际 `ZF_NEW_FETCH_JS`，在 Node HTTP/DOM 测试环境中通过授权会话请求学校真实接口，确认桥接结果为 23 条原始课程记录和 11 条完整真实作息。这不是 Android WebView 真机测试。

`scripts/test-zf-routine-fetch.cjs` 执行实际生产脚本，覆盖 8/10/11/12/13 节、无表头的完整接口、失败/超时/登录失效、旧表头不覆盖接口、冲突和非法时间、多个或缺失校区、空学期等情况。JVM 测试验证真实 11 节时间进入确认和序列化往返、完整作息不截断、超出部分保留空值、已有作息优先。

测试资源 `fzfu-routine.json` 仅包含学校作息编号和时间。账号、密码、会话、个人课表没有写入仓库或交付文件。当前没有 Android 设备，手机、平板和实际 WebView 点击流程仍需设备验收。
