# P3 动效收敛：首批实现

日期：2026-10-11。基线为 `f38141a`，用户确认 P2 无明显问题后继续。

## 已修复

- 底栏原先以“上次落位序号相同”为条件提前结束。A → B 的动画未结束就点回 A 时，旧动画被取消，新动画又被跳过，滑块可能停在中间。现在每次选择都从当前实际位置追随新目标，逻辑选择即时更新，不等待动画结束。
- 底栏窗口尺寸/像素密度变化时，原先可能因序号未变而保留旧位置。现在记录独立的几何快照，首次布局/重建/几何变化直接对齐；正常切换才播放位移动画。Dock 与普通药丸栏分别负责自身几何，避免驱动同一个滑块。
- 分段选择原先把滑块位置四舍五入后计算文字覆盖色，文字会跳到下一格，和背景滑块不同步。现在文字覆盖率直接读动画浮点位置。空选项安全返回，选项减少时修正越界位置；补充 Tab 与选中态语义。
- 设置折叠内容使用统一的无回弹尺寸曲线，箭头与选择指示器使用同一快速无回弹响应；透明度仍走 Material effects。展开、折叠被反向操作打断时由 Compose 接续，不排队播放。
- 清理导航文件里不参与执行的取消弹簧，以及把预测性返回参数误写成手势进度的注释。真正的手势 seek、取消和提交继续由 Navigation3 管理。

## 动效职责表

| 类型 | 实现入口 | 中断 / 状态 / 减少动态效果 |
| --- | --- | --- |
| 点按 | NoRippleClickable | 即时轻遮罩，释放/取消撤销；不增加缩放或业务延迟 |
| 导航滑块 | PillBarState.moveThumb + SleepyThumbSpring | LaunchedEffect 取消旧目标，从当前值追随新目标；几何变化 snap；遵循 Compose MotionDurationScale |
| 分段选择 | SegmentedSwitcher + SleepyThumbSpring | 选中值即时生效；颜色和位置同一真值；旧动画取消后接续 |
| 折叠内容 | sleepyContentSizeSpec / sleepyExpandEnter/Exit | NoBouncy + Medium；保留内容尺寸逻辑，透明度使用 Material effects；关闭系统动画时有限动画到达目标 |
| 折叠箭头 | sleepyIndicatorSpec | 与滑块共享无回弹 spring，快速点按只追随最新展开态 |
| 同级主 tab | MainTabs + SaveableStateHolder | 保留既有即时内容切换与页面状态，不给每张卡片追加入场动画 |
| 子页 push/pop | SleepyMaterialTransition + NavDisplay | 保留现有 220ms / 0.92 缩放基线；预测性返回由框架接管，没有第二个手写进度循环 |
| 弹层 | Material BottomSheet/Dialog | 保留标准状态机；查看/编辑等业务动作不依赖动画结束回调。ImportSheet 防上窜 inset 修复保持原样 |
| 课程拖动 | GridCourseInteraction | 跟随手指，取消不提交，落点确认才触发移动；P2 已加入窗口变化取消 |
| 加载 | GlasenseSpinner / Compose InfiniteTransition | 只在加载组件存在时运行；系统零倍率的实际设备表现仍待确认 |
