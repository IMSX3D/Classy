# 新手教学与可重复使用指南

## 设计与实现

- 我的新增固定「使用指南」入口；八个任务主题可独立重看。目录另有「重新体验快速上手」。
- 新安装、首次从启动器打开时以欢迎页作为初始导航内容，不先闪现课表再弹教程。升级用户及外部导入/深链不自动打断。欢迎可以导入、进入示例或跳过；教程历史独立于恢复默认设置。
- 欢迎导入进入原有课表管理导入选择，不伪造登录或自动导入。真实课程首屏沿用已有周次/更多引导，不叠加第二个强制弹窗。
- 看课表、导入更新、编辑调课、外观、小组件、提醒、学期安排、作息各三步；步骤短文解释操作目的、真实入口与重要边界。真实功能入口与示例区域明确区分。
- 示例课程展开、周次选择、灰显切换、课程改名并保存、配色/标题位置、组件内容示意、通知提前时间、周次图示和作息切换均为局部可保存状态，不调用课表仓库、通知发送或 AppPrefs 写入。
- 演示是简化教学模型，不冒充真实系统通知或桌面宿主预览。已有实际组件管理承担设备添加；不宣称厂商自动添加或原子岛普遍可用。
- 复用 SettingsScaffold 的安全区、720dp 阅读限宽、可滚动布局与 Navigation3 父子导航。按钮/选项自适应换行，课程详情展开使用公共尺寸动效；关闭系统动画仍可操作。
- 用户主动切换教程步骤时回到步骤标题；旋转/返回时恢复当前步骤及示例，不能因恢复再滚动。示例编辑无需未保存阻拦，因为不是用户课程编辑。
