# 页面退出连续性审查（2026-10-11）

用户底线：所有页面切换必须平滑连贯。范围包括进入、顶部返回、系统返回、预测性返回取消/完成、保存退出、全屏覆盖层及独立 Activity。动画关闭时尊重系统，仍须保持内容与状态正确。不以加长动画掩盖初始化或数据清空。

## 本次修复

录屏退出课程编辑时，节次/周次/教师先变成新建默认值。SleepyNavHost 的 remember key 含 session.editingCourse?.id，而 onBack/onSaved 在 pop 前清会话，导致仍在离场的编辑页被重建为新建表单。改为以路由身份持有编辑对象快照，直到导航条目销毁。DisposableEffect 在没有其他编辑课程路由时兜底清理系统返回留下的会话。

课程、课表、作息编辑以前无条件 BackHandler，会阻挡 NavDisplay 的预测性返回。现仅在修改未保存、写入忙碌或新建清理需要处理时拦截；无修改返回交导航处理。确认放弃后仍走公共 pop 动画，保存期间仍禁止退出。

AppearanceScreen 中自定义主题编辑以 if(showEditor) 直接装卸，未经过 NavDisplay。补 AnimatedVisibility，复用 sleepyForwardEnter/sleepyPopExit，保留离场 editing 对象。未新增另一套曲线或延时 pop。

## 审查范围与状态

- NavDisplay 所有注册路由：共用 forward/pop/predictive transform 接线存在；本次修改数据生命周期与拦截条件，未调整公共 220ms/0.92 参数。
- 课程详情：显式关闭/编辑等先 hide sheet；保留平台面板关闭机制。
- 新课表/新作息清理：保留条件式 BackHandler，避免预测性取消误删除数据。删除后数据库对象消失与离场画面需要设备复核。
- 课程列表主从选择：返回先取消选中详情，是局部布局状态，需单独做主从过渡验收。
- 导入确认/作息预览：ImportReviewPage 使用 Dialog 或 Activity 内嵌内容，不属于 NavDisplay。独立窗口/Activity 的过渡需设备验证，不能以导航转场存在视为通过。
- 教务登录、导入、桌面组件配置与系统 Activity 边界：需独立验证系统窗口转场。
- 主题色编辑的颜色/删除子弹窗保留各自关闭拦截。
