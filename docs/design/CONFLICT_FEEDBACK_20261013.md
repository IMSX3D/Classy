## 发现与修复

1. STACK / RAIL 的右下命中区、FOLD 折角及隐藏课占位用透明 Box 接点击，但公共反馈默认画矩形，独立于真实卡形。改为共享 InteractionSource：透明命中区不绘制遮罩，反馈由已裁切的卡面或折角路径绘制；删除底卡重复的父级 clickable。
2. 三层轮换的最后命中区可能属于最底层，单独反馈会被第二层遮住。三层及以上共用轮换反馈源，露出的底卡接收反馈；两层保留目标课程反馈源，折角使用折角反馈源。轮换、默认置顶和详情回调语义未改。
3. 平板当前日已结束课程截图出现上下两层课名重影。根因每张卡整体 alpha，底层文字透过顶卡。叠卡改为将变淡程度合成到不透明卡面/文字颜色，折角与虚线颜色同步；不修改普通无冲突课卡，也不更改保存的课程颜色。自定义背景下冲突卡仍优先保证不透底的可读性。
