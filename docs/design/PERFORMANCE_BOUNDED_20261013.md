## 决策

1. 充分编译对设置链有小幅样本收益，仍有14–15个超时帧，不能解决任务；对弹层超时/P99没有稳定收益。不把shell编译操作包装成用户可获得的修复，也没有据此添加全包编译规则。
2. 设置缓存候选：在主题作用域提供容量128的TextMeasurer，分段行标题/选项宽度复用缓存；保持字体密度、页面结构和动画不变。三组超时均16，不优于相同编译模式原版，完整撤回SettingsCards.kt/Theme.kt改动。只做benchmark构建与实测；未采用，无需让用户验收候选视觉。
3. 弹层已有跟踪显示同步系统窗口/焦点等待；本轮编译对照不改善，与这条线索相容，但不能证明全部长帧都由系统造成。没有证明安全有效的应用层替换。未关闭焦点/无障碍，未改成语义不同的普通对话框或常驻不可见窗口，也未升级整套实验依赖。
4. 当前能力与时间边界下，不能可靠完成“全页面完全流畅”的目标。具体闪屏/错位/阻塞仍应正常修复；这项未形成收益的广泛性能优化应停止滚动投入，不能用继续改装饰替代完成。
