## 共用设计改动

- 新增 `DiscardChangesDialog`，属于现有确认弹窗的行为封装，不增加新的视觉类型。
- `DialogActionButtons` 支持取消按钮禁用；长文本可换行、高度可增长；横排/竖排采用同一套主题主按钮色。系统字体放大时仍需设备验收。
- 课程详情复用 `GlasenseButton` 与 `GlasenseIconButton`；先结束面板，再开启编辑，同一次关闭期间不重复接受编辑。
- 普通返回和预测性返回都把父页放在下层，父页保持静止。进入动画暂保留既有 220ms/0.92 基线，未在无设备条件下重新定义整套曲线。
- 表单修改比较覆盖课名、别名、周次、各时段、颜色、地点和特殊作息草稿；不将高级区域展开状态和校验标记当作修改。

## 仍需逐步推广/验证

1. 课程编辑的内存会话丢失后仍沿用原有退栈策略，本轮未改成完整跨进程恢复。
2. 课程组色已有即时保存路径，与表单未保存内容分别处理；退出确认只承诺丢弃未保存修改。
3. 当前调课表单短屏/大字体可能较长，先用滚动保证信息完整，再通过设备体验决定是否升级为独立页面。
4. 导入、作息、新课表的草稿与删除流程仍按原行为运行，后续按相同清单逐项审查。
5. 无 Android 设备，不宣称连续触摸、预测性手势、键盘遮挡、手机/平板分屏和帧性能已经验证。

## 验收操作

从今日进入课程详情，连续点击编辑，确认只开一个编辑页；修改并返回，选择继续编辑后内容保留，选择放弃后回今日。重新进入并保存仍回今日。无修改返回不出现确认。只展开高级设置返回也不出现确认。

调课修改目标后取消，继续编辑应保留当前输入；保存中不能再次确认或关闭。选择冲突目标，只有明确“仍然调课”才提交。编辑和调课的取消/关闭表现一致。

设置即时开关无需二次保存；进入子页后通过顶部、系统和手势返回，父页不在前景遮挡退出页。检查中文/英文、1.0/1.3/1.5 字体、手机窄屏和平板分屏，以及动画关闭后的全部操作。
