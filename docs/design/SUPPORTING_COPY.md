# 提示文案与信息层级

2026-10-11。适用于全应用，延续简洁、美观、统一的设计原则。

## 何时需要说明

| 情形 | 处理 |
| --- | --- |
| 标题和选项即可理解，如语言、今日摘要、课前提醒 | 不重复解释；有时间设置和预览时也不再加同义句 |
| 有范围或前提，如默认视图、仅影响小组件、Android 版本限制 | 控件附近保留一句，先说作用或适用范围 |
| 有不直观的后果，如批量替换周次、更换作息、同日补课替换 | 操作前说明，不能只在操作后提示 |
| 数据删除、覆盖、恢复默认 | 保留确认和具体影响，不为简洁而删掉后果 |
| 首次使用或复杂规则 | 默认展示下一步；详细规则按需展开，不反复弹窗 |
| 输入错误、权限缺失、网络失败 | 就近说明发生了什么和下一步；保留错误语义色 |
| 无数据 | 说明当前状态，给出创建、导入等可执行入口 |
| 格式协议、开源署名、隐私说明 | 保留必要准确性，不按普通操作提示随意删改 |

## 排版与表达

- 普通提示使用 `SupportingText` 或同等 `bodyMedium`：14sp、20sp 行高，跟随系统字体缩放，`onSurfaceVariant`。不使用 11sp 角标样式，不额外降低透明度。
- 标题到说明间隔一般 4dp；说明紧邻所属控件，卡片内左右 16dp。错误、不可逆后果与一般说明区分，不给所有提示加警告图标。
- 带说明的分段选择采用“标题—说明—选项”的上下结构，避免说明挤在按钮左侧。无说明时仍根据可用宽度决定是否换行。
- 不限制提示行数、不用省略号隐藏关键后果，不通过固定高度或缩小字体挤入窄屏。
- 优先用日常词：上课时段、补课安排、主色、背景。避免槽位、映射、容器、Prompt 等面向实现的术语。
- 一句表达一件事，先结果再条件。较长操作使用步骤；详细规则可折叠，但不能隐藏当前错误或操作前必须知道的后果。
- 中英同步维护；例子必须与真实行为一致。不要把尚未测试的平台能力写成承诺。

## 本轮落地

- 课表显示按默认视图与时间、网格、周视图、显示星期、节假日与灰显、实验室组织。灰显样式迁到上级页，沿用原偏好键。
- 调休页默认展示假期名称、日期和已安排天数，逐日安排按需展开，沿用共用无回弹折叠。标题右侧保留编辑；明确放假日期到补课日期方向。数据源和刷新放在页尾。
- 规则说明分常用操作与可展开帮助；保留一目标日期只能有一项安排的实际规则，不改排课算法。
- 共用设置行、分组说明、滑杆说明和脚注统一正文样式；修复分段控件上下布局的重复内边距。
- 审查中文资源中 hint / subtitle / sub / desc / note / body 等文案及调用，精简导入、课程编辑、作息、外观、小组件、调休、教务和分享说明。提醒页去除与标题、时间和预览重复的三项说明。
- 将作息编辑、拖动课程中八条硬编码提示移到中英资源。其他历史硬编码控件标题和底层错误消息不属于本轮全部国际化改造的完成声明。
- 小组件页按“已有小组件—添加与帮助—通用显示—刷新”组织。四种添加样式与厂商帮助按需展开，诊断详情通过复制用于反馈。原名/别名实际是全局偏好，移到通用显示；单个组件编辑页仅设置课表绑定。沿用原偏好、系统添加确认和刷新流程。
