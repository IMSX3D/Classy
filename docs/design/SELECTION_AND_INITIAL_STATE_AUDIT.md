# 选中背景与首次显示审查（2026-10-11）

## 圆角组选中背景
用户截图的上沿留边由 WidgetEditScheduleSection 内部 Column 的上下 4dp padding 引起，与动画时长无关。选中行未占据这 4dp，因此第一项顶部/最后一项底部露出未选中卡色。改用公共 SettingsGroupCard 的唯一圆角裁剪、零外部间距的 selectableGroup，各行保留内部 16/14dp 内容边距。选中文字和对勾使用 onPrimaryContainer 配对色。

WidgetEditAliasSection 中存在相同复制结构，一并修复；当前编辑页仅注册 schedule section，alias 修复是保留组件的预防性处理，不新增入口。

源码核对：课表切换、冲突课程置顶、导出选择、作息绑定、外观课程配色、所有课表使用独立行/卡片的 clip→background→内部 padding；未发现相同的卡片上下裸露带。SegmentedSwitcher 的四周轨道留白是有意的对称滑块结构，不能机械移除；PillNavigationBar/Dock 的指示器沿用测量后的定位保护。本次不宣称所有设备像素均已验收。

## 首次定位与异步表单
扫描 UI 层 scrollTo/animateScroll/scrollToPage、焦点请求、编辑表单加载及指示器初值。

- 课程编辑：保留前轮按源课程匹配目标时段、加载后以初始索引创建列表，禁止进入后再次强制滚动。
- 课表翻周：初始页来自 selectedWeek，后续滚动用于状态同步，已有手势/恢复保护；未更改。课程数据与目标周次在同次状态更新中发布。冷启动空态及跨课表加载仍属于需设备观察的范围，不能据源码证明无任何视觉跳变。
- 学校字母定位：由用户点击触发，属于预期滚动。
- 搜索/提醒输入焦点：用户进入输入操作后请求焦点，不属于自动跳至表单时段。
- 教务 WebView：SEP 桌面模式在网页加载完修改 viewport 并回到顶部，是站点兼容路径，可能重排，不与原生表单初始化混为一谈；本轮不更改该兼容脚本，需站点实测后单独评估。
- 作息编辑、课表编辑：发现 StateFlow 初始 emptyList 被当作真实结果，前者可能先显示“未找到”，后者绑定作息可能先用本表备份再回填。新增 nullable periodTablesSnapshot，null 表示未收到数据库结果，空列表表示读取完成但没有记录；两个表单等快照就绪后构造字段。其他列表继续使用原非空列表接口，避免扩大改动。
