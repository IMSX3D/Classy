## 4×4 色条跟随（2026-10-11）

原因：WeekGridWidgetProvider 的 Canvas 路径一直填充课程色，未读取课程外观偏好；外观页切换课程样式时也没有主动刷新小组件。

现在读取 App 的色条/填充样式。色条模式使用中性卡面、主题文字和共享 softenedIndicator 混色；3dp 色条在窄列中限制宽度，文字避开色条。取消重复描边，保留填充模式和小组件独立无色设置的原有语义。外观页切换后通过 WidgetUpdater 刷新已有组件。极低高度时已有色带降级继续保留，不在无法容纳文字时强塞课程卡。

本周中英文静态预览调整课程分布、文字居中和教室对齐；对照图仅示意两种样式，不是实际桌面截图，也不随用户设置动态切换。真实组件按实际课表绘制，不改变课程时间与空白节次。

验证：309 项现有小组件 JVM 测试通过；Debug APK 构建与 ARM64 签名校验通过，diff 检查通过。没有连接 Android 设备，实际 Canvas 像素、桌面即时刷新、深色/长课名/多列冲突、手机及平板缩放仍待安装检查。可在“我的 → 外观 → 课程配色”切换色条/填充对照，无需重新添加组件。

## 圆角安全区与统一底色（2026-10-11）

用户截图指出四种桌面组件内容贴近系统圆角、双日列表呈现突兀矩形底色。本次按注册的四个 receiver 核对正式路径：今日小号/标准共享 CourseRowWidget 的 widget_course_list；最近两天使用 TwoDayColumnsPusher 的 widget_twoday_columns；本周使用 widget_weekgrid_card / WeekGridRowFactory。

三个正式容器共用 widget_content_inset = 16dp，顶部标题、日期及底部滚动视口一起内收，滚动截断留在内容区，不再紧贴外框圆角。今日标题与正文对齐，去除重复横向内边距；双日各列保留 6dp 内侧间距。新增双日外层裁剪容器，避免动态 setBackgroundColor 替换根背景时丢失圆角 outline。新增边距计入今日列表填充行的可用高度估算。

今日两种尺寸与双日共用的课程行改用 scheme.bg，与外框、空态及透明填充行一致；完成课程的混色也以同一底色计算。本周色条模式改用同一底色；填充模式仍显示课程色。四种组件不新增阴影、内嵌面板或装饰。

边界：16dp 是本轮统一安全留白，并非对所有厂商圆角的动态测量。课程较多时仍正常滚动，视口末尾可能显示部分课程；本轮解决内容紧贴外框和底色割裂，不将滚动列表变成分页。手机、平板、缩放、大字号、明暗主题及 OEM 桌面最终观感需安装验证。

验证：312 项小组件测试通过，0 失败/错误/跳过；Debug 构建与三种架构签名校验通过。XML 检查确认三个正式容器使用共享安全边距且裁剪根与染色内容分离。未连接设备，本轮没有真机截图或平板验收结论。
