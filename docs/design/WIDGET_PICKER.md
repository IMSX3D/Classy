## 4×4 色条跟随（2026-10-11）

原因：WeekGridWidgetProvider 的 Canvas 路径一直填充课程色，未读取课程外观偏好；外观页切换课程样式时也没有主动刷新小组件。

现在读取 App 的色条/填充样式。色条模式使用中性卡面、主题文字和共享 softenedIndicator 混色；3dp 色条在窄列中限制宽度，文字避开色条。取消重复描边，保留填充模式和小组件独立无色设置的原有语义。外观页切换后通过 WidgetUpdater 刷新已有组件。极低高度时已有色带降级继续保留，不在无法容纳文字时强塞课程卡。

本周中英文静态预览调整课程分布、文字居中和教室对齐；对照图仅示意两种样式，不是实际桌面截图，也不随用户设置动态切换。真实组件按实际课表绘制，不改变课程时间与空白节次。

验证：309 项现有小组件 JVM 测试通过；Debug APK 构建与 ARM64 签名校验通过，diff 检查通过。没有连接 Android 设备，实际 Canvas 像素、桌面即时刷新、深色/长课名/多列冲突、手机及平板缩放仍待安装检查。可在“我的 → 外观 → 课程配色”切换色条/填充对照，无需重新添加组件。


## 正式渲染路径纠正（录屏回归，2026-10-11）

上一节对应 0306b6d 的“桌面已跟随”结论有误：修改仅作用于保留备用的 renderBitmap，生产 renderWidget 实际绑定 WeekGridRowService；309 项旧测试未覆盖外观偏好到该工厂的连接。用户录屏显示 App 已用色条、桌面仍是填充，与此断链一致。

本次修正 WeekGridRowFactory：数据刷新时快照课程样式及小组件无色偏好；每门课的 RemoteViews 块增加连续 3dp 色条，中性卡面与主题文字，填充时明确隐藏色条并还原文字边距，防止桌面复用布局后残留。跨节次仍是单个块，已结束课程继续沿用原灰显逻辑，课程颜色读取带同组行的公共入口。Provider 原有 notifyAppWidgetViewDataChanged 刷新集合内容，外观页已有的主动刷新继续保留。

新增正式路径接线回归测试，覆盖 provider → service → 外观快照 → 色条布局，以及模式切换刷新集合。此类源码测试不能证明实际 RemoteViews 像素效果，需与 Android 构建、Lint 和后续真机验收结合；不再用备用位图或静态预览替代实际组件验收。
