# 小组件选择器优化

顺序：1 今日小号（2×2）→ 2 今日标准（4×2）→ 3 最近两天（4×2）→ 4 本周（4×4）。声明顺序和名称编号同步调整，保留原组件身份。Android 没有跨桌面的强制排序 API，具体呈现仍需目标桌面确认。

四种预览使用统一的虚构示例、日期、颜色、卡片和排版；图片与 previewLayout 共用资源，避免不同桌面出现两套风格。附中文和英文素材，生成器为 scripts/generate-widget-previews.py。附图为静态素材对照，不是实际桌面截图。

309 项小组件相关现有测试通过，0 失败/错误；Debug 构建和 ARM64 签名校验通过。桌面缓存刷新与最终排序尚未真机验证。安装后重新打开小组件选择器查看；若仍显示旧素材，可稍后再打开或重启手机，不要清除桌面数据。

普通安卓手机使用 arm64-v8a；可覆盖同签名测试版，与正式版共存。版本仍为 0.0.9-debug。仅本地提交，不推送，不更改原 tag/Release。
