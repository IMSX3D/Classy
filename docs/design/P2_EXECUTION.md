# P2 页面推广与双栏试点

日期：2026-10-11。基线为 P1 提交 `0e598b4`。用户反馈 P1 无明显问题后继续推进。

## 本轮实现

1. `SettingsScaffold` 默认采用 720dp 阅读容器，底部固定操作与正文同宽；统一在页面外层处理 IME 高度。新增/编辑、外观、提醒、作息、导出及小组件设置等使用方同步生效。
2. 「管理」「我的」「选择学校」居中限宽。学校页保留自己的搜索、字母索引与列表状态，不改变索引项编号。
3. 课程清单改为摘要列表与安排详情。宽屏左列表、右详情，未选择时显示引导；窄屏先列表、再详情。选择用课程行 ID 保存，列表及详情各自保存滚动位置；返回先清除选择，再退出页面。
4. 双栏按扣除系统安全区后的内容宽高判断：宽至少 840dp、高至少 480dp；大字体要求更宽空间（至少 720dp × 字体倍率）。不按设备型号判断，窄分屏或低高度退回单栏。
5. 周列表冲突栏空间不足时纵向排列同一组，并显示冲突提示，避免继续压小字体、隐藏时间来硬塞多栏。课表网格保留用户密度、缩放和颜色呈现设置；窗口尺寸/密度变化时取消未提交拖动。
6. 课程详情弹层允许正文滚动，长备注及大字体不再依赖整段内容一次塞进可见区域。
7. 新增/编辑课程保存名称、别名、周次、多时段草稿、特殊节次暂存与原课程行身份；恢复时不从数据库重新覆盖已恢复的草稿。编辑模式加载后同步新增时段 ID，避免多时段编辑中新增卡片复用已有 ID。
8. 课表编辑、作息编辑保存名称、周次/日期、绑定选择、时段输入与自动模式配置。草稿保存不校验或规范化未完成输入，不触发写库。作息保存前的影响确认在重建后需重新发起，未承诺恢复异步确认过程。
