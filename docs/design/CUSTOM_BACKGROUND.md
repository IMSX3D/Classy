# 自定义背景：候选方案与参考调研

日期：2026-10-11。用户表示后续可能引入；目前仅调研和预留设计接口，未确认实施、未增加设置或图片处理依赖。

补充：[Chrnova 自定义背景评估](CHRNOVA_BACKGROUND_REVIEW.md)。建议采用其手势期间辅助线、缩放/复位和背景/卡面分层思路；Classy 需另行保证图片持久存储、平板焦点裁切与可读性下限。

## 建议的首版范围

本地静态图片，建议首先支持课表与今日页的页面背景；全应用共享一个背景设置，暂不引入按课表、按页面分别配置的复杂规则。设置、编辑、导入和确认弹窗保留稳定表面。该范围是建议，实施前再确定。

用户流程：外观 → 背景 → 选择图片 → 调整位置/缩放并预览 → 应用；随时恢复默认。预览取消保留旧背景。提供有限、容易理解的柔化控制，优先一个强度选项，不向普通用户暴露遮罩、折射、饱和度等成组渲染参数。

背景与课程色独立：不因换壁纸重新分配课程颜色，不改变课程、主题或排版设置。柔和色条继续担当课程识别。首版不加入视频、动态壁纸、视差、联网壁纸库或整页持续模糊。

## 与设计体系和平板的配合

- 采用页面背景、可读内容表面、悬浮控制层三个绘制层次。课程卡与表单维持可靠底色；玻璃仅对选定悬浮控制层采样，不能连文字一起模糊。
- 背景不只覆盖一层颜色即可完成：现有页面与网格会自行绘制不透明底色，实施时需统一背景归属并保留卡面隔离，避免设置成功却看不见图片，或为露出图片把整张课表变透明。
- 大屏、分屏和旋转使用当前内容区尺寸裁切，保持比例、不拉伸图片。保存归一化焦点与缩放，而非某一手机上的像素裁切框；首版可先使用共享焦点，根据预览结果再判断是否需要独立横/竖屏焦点。
- 预览至少覆盖手机竖屏、平板横屏、窄分屏。主体无法在所有比例完整显示时允许用户调整焦点，不承诺任意图片在任意窗口都不被裁切。
- 不依赖图片平均亮度保证文字可读：同一张图片可能同时有高亮与深色区域。页面标题、时间轴和表头也需稳定底色/局部遮罩，普通正文对比度目标仍为 4.5:1。
- 原图、柔化和玻璃不能各自重复全尺寸解码或独立循环渲染；关闭玻璃时背景功能仍然完整可用。

## 数据与图片处理

当前代码搜索未发现已有自定义图片背景入口；已有 Coil 2.7.0 和 Activity Compose，可优先复用现有依赖。

建议通过系统 Photo Picker 选择单张图片，核对 Activity Result 在目标系统上的可用性与回退路径。兼容设备按需使用系统文档选择器，不要求全面读取相册。

选择成功后在后台读取尺寸与方向，限制文件/像素规模，按目标显示范围采样解码并处理 EXIF 方向。将经过处理的副本原子写入应用管理的持久目录，再切换当前配置；仅长期保存临时 URI 或缓存目录路径不够可靠。处理失败维持旧图并给出提示。

缓存以资源版本与目标尺寸分档，窗口连续调整时复用缓存并合并解码请求；限制解码并发与内存，取消过时任务。不要将参考项目的最大边长直接当作所有平板的最佳数值。超大照片、损坏文件、透明图、低存储、来源不可读、重启与备份恢复均需验证。

应用内部复制完成后，原相册文件移动/删除不应使背景丢失。替换成功后再清理无引用旧副本。备份需明确选择包含副本与配置，或恢复时清除无效引用回到默认；普通课表导出默认不携带个人背景照片。

## 开发依赖与验收

P1 预留背景/内容/悬浮层的职责边界，P2 的平板适配保证背景能依容器裁切；不提前实现一个没有用途的完整渲染框架。

若确定实施，建议在 P2 基础适配之后、P4 玻璃正式接入之前，独立安排一轮“静态背景体验包”。玻璃若先试验，可用固定测试图片验证采样，无需等待整个背景设置功能。

验收包括选择/取消/应用/恢复默认；明暗图与复杂纹理下的全页文字可读性；手机/平板/分屏裁切；替换失败保留旧背景；重启与恢复；快速换图、超大图、滚动、切周与内存对照。图片处理过程中不能阻塞课表操作。
