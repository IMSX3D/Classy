## 本轮实现记录

- 课程列表：窄屏详情进入/返回复用导航的 forward/pop 变换；宽屏或跨断点使用同周期淡入淡出，避免横向布局变化附加大幅缩放。AnimatedContent 读取场景内的课程对象与详情滚动状态，退出时不读取已清空的 live selection。保留原列表滚动位置、选中 ID 与自适应判断。局部主从返回目前是完成手势后播放过渡，不宣称已实现跟手预测性拖动。
- 主题编辑：使用公共 DiscardChangesDialog，顶部与系统返回共用判断；选色子弹窗返回仍先关闭子层。新增 CustomThemeDraftSaver 保存完整草稿与原始基线，外观页保存编辑器开关和目标主题 ID，重建时不丢入口。已有 AnimatedVisibility 保留。未改主题持久化和删除语义。
- 导入确认：ImportReviewPage 的全屏 Dialog 共用 ClassyFullScreenTaskAnimation，系统窗口管理器负责进出；时长/缩放对应页面基线（220ms、0.92，进入透明度110ms）。覆盖导入确认和作息草稿子窗口。useWindow=false 的教务 Activity 内嵌路径保留宿主逻辑，仍列为后续窗口层级审查项，不宣称已完成整条教务 Activity 转场。

验收步骤：课程列表打开/返回详情，快速换课与跨宽屏断点；主题编辑修改后返回→继续编辑/放弃，保存返回，旋转恢复；导入确认进入作息编辑，返回取消/放弃、确认写回、最终取消导入和失败重试。所有项覆盖中文/English、明暗、大字体、短屏、平板/分屏、动画关闭。
