## 原则

**简洁、美观、统一、成一套完整的体系。** 每个视觉效果都应帮助用户理解信息、操作结果或页面关系。没有这些作用的装饰可以删除。允许体系演进，但同类组件必须一起演进，不能在新页面另起一套。

推荐方向是「柔和、清爽的信息界面」：中性表面承载内容，课程色帮助定位，主题色表达操作。课表是高密度阅读工具，辨认课程与时间的优先级高于材质表现。

已确认的组合：轻纸感现代极简作为视觉基础，柔和色条作为课程识别特征，克制且跟手的动效作为交互语言，局部玻璃作为可选材质。轻纸感通过表面、排版与留白体现，不添加纸张纹理。圆点索引仅保留为历史探索，不进入实施计划。编辑式排版主要用于今日页的信息层级；密集课表优先保证信息密度。

## UI 规则

信息按当前任务归属呈现：今日页回答今天何时、何地上什么课；桌面组件名称、规格和排序只出现在组件选择/管理场景。新增信息前明确它帮助用户作何判断，核对所在页面及重复信息；没有作用则删去，不用补说明解释错放的信息。复用文案必须语义与场景相同。日期/计数已有清楚表达时，不另加重复标题行。每次修改共享文案检查所有消费位置，整体验收逐页面审查信息归属。

紧凑不等于拥挤：通过收纳低频操作、删除重复说明和明确层级简化界面；保留可读间距、内容区留白与至少48dp的主要触达高度。不能用压缩点击区域换取视觉上的短小。

2026-10-12：载体与信息密度必须按完整任务验收。方式选择的底部面板不同时容纳输入、长帮助和预览；完整任务页须有可见返回、系统栏明暗适配和键盘避让。既有组件使用位置按[重审清单](INTERACTION_REVIEW_20261012.md)重新核对，公共组件复用不代表设计通过。

文字与尾部开关/箭头/按钮同排时，必须先为控件预留宽度与间距，文字在剩余宽度内换行；禁止用无权重文字加 SpaceBetween 假定不会重叠。开关设置复用 SettingsSwitchRow。验收包含窄屏、长中英文及 1.5 倍字号，并核对实际业务页面。

2026-10-11 补充底线：每一个部件都必须有意义，不割裂，形成统一整体。统一单位是完整操作链路，而不只是控件外形或动画参数。每个入口明确“触发—即时反馈—结果呈现—返回/取消—状态保留”；先按任务决定原位更新、展开、弹层或页面，再选择对应动效。没有明确作用的装饰和重复入口应删减，同类操作保持可预期。后续按 [高频交互统一清单](INTERACTION_UNIFICATION.md) 推进，优先级高于玻璃正式接入。

| 领域 | 统一规则 |
| --- | --- |
| 色彩 | 页面、卡片、文字读取主题语义色；通过 GlasenseColorBridge 与 Material 保持同源。禁止业务页面另配一套黑白色。 |
| 课程识别 | 保留既有课程色分配。色条是辅助识别，不承载唯一信息；课程名、时间始终可独立阅读。 |
| 色条 | 网格、周列表、今日统一为 3dp 基准宽（网格/周列表沿用布局缩放）；用 68% 课程强调色与 32% 卡面色混合。时间使用主题中性文字。自定义色仅改变呈现，不改保存值；填充模式保留。 |
| 字体 | 复用主题字体层级。课名优先，时间次之，地点与教师为补充；不用彩色小字承担核心阅读。支持系统字体放大。 |
| 间距 | ClassyLayout 维护普通页面左右 16dp；今日、管理、我的、学校选择及共用设置/编辑页面阅读容器最大 720dp；内部以 4dp 为基础，常用 8/12/16/24dp。密集课表允许专用尺度，不强行套设置页尺寸。 |
| 圆角 | 分组卡片复用公共 cardShape；紧凑课程卡保留密度适配；胶囊用于选择与导航，避免所有容器都变成胶囊。 |
| 反馈 | 公共 noRippleClickable 以中性遮罩确认按压（8%）/键盘焦点（6%），松手即时撤销；选中态可辨认。一次操作只有一个主要视觉反馈，不同时叠加缩放、弹跳、闪光与震动。 |
| 入口 | 一个主要任务有一个稳定的主入口。「我的」保留提醒、外观、小组件、设置、关于；课表管理使用现有 tab。 |
| 语言 | 简体中文、English。旧繁体偏好映射简体，旧日语/西班牙语偏好映射 English；更新说明只维护中英。 |

混色数值是本轮候选基线，需要真机明暗主题与高饱和自定义色复核；不能为了降低色条对比度同时降低正文可读性。

平板是正式支持目标：按当前可用窗口适配导航与内容，不将手机界面等比例放大。列表/表单合理限宽，课表优先保证可读列宽，双栏复用状态和导航语义；旋转、分屏和键盘变化不能丢失编辑内容。具体范围与验收见 [平板适配方案](TABLET_ADAPTATION.md)。

## 动效规则

提示文案的必要性、字号、布局与措辞统一遵循 [提示文案规范](SUPPORTING_COPY.md)。普通说明使用 14sp 辅助正文；直观操作不重复解释，复杂规则按需展开，数据影响在操作前说明。

| 场景 | 目的和行为 |
| --- | --- |
| 点按 | 确认触达，短促且不挪动排版；优先公共按压反馈。 |
| 分段选择 / 底栏 | 一个选中指示器跟随目标；快速连点从当前状态接续，不排队播放，不重复播放入场。 |
| 同级 tab | 表达切换；避免每张卡片依次飞入。页面状态与滚动位置保留。 |
| 进入详情 / 返回 | 表达层级，进入与返回成对；跟随系统预测性返回，不额外叠加第二段动画。 |
| 展开 / 弹层 | 从触发位置或屏幕边缘有逻辑地展开；文字清楚，关闭可被打断，键盘 inset 只有一个负责人。 |
| 拖动课程 | 跟手优先；确认落点再给予一次收束反馈，保存与撤销不等待装饰动画。 |
| 减少动态效果 | 尊重系统动画缩放；关闭动画仍能完成全部操作。材质开关不改变交互语义。 |

现有实现：`SleepyMotion.kt` 用无回弹 `sleepyContentSizeSpec` 处理折叠尺寸、Material effects 处理透明度；底栏、分段器与折叠箭头共享无回弹的 `SleepyThumbSpring`；`SleepyMaterialTransition.kt` 单独维护 Navigation3 预测性返回（220ms 转场、0.92 缩放）。目前并不是全应用只有一个动效参数源。不要直接把参考项目的 spring 常量并进来。

P3 首批已修复底栏快速切回时的中断、尺寸变化对齐与分段文字颜色跳变，详见 [P3 实施记录](P3_EXECUTION.md)。设备验收继续验证页面切换的幅度与中断连续性。对 0.92 缩放是否过大做真机对照，再统一调整导航入口；不靠额外模糊掩盖不连续。公共 motion 文件中指向不存在扫描脚本的旧注释已移除；当前没有自动动效一致性扫描。

## 可选玻璃材质

结论：Classy 适合**局部玻璃**。默认中性实色，探索开关只替换悬浮控制层材质。建议首个原型仅覆盖底部 Dock；是否扩展到短小浮动菜单，取决于可读性和帧时间测量。

不建议在课程网格、编辑表单和长设置列表上铺满折射：它们需要稳定阅读，连续小块玻璃也会放大渲染成本。现有 Dock 的 0.86 alpha 背景只是半透明，不是真正的背景采样与折射。

实现约束：

- 统一一个材质入口，提供 Solid / Glass 两种表现，布局、点击范围、圆角和文字层保持一致。
- 背景采样层与玻璃层互为兄弟，避免把玻璃自身再次采进背景；不模糊文字与图标。
- 控制折射幅度，以稳定底色保证前景对比度；壁纸变化不能让文字忽明忽暗。
- 低版本与不支持效果的设备回退实色；具体 API 下限取决于选定依赖及锁定版本，不能把全部玻璃效果统称为 Android 12 可用。
- 开启只是偏好，不保证强制运行昂贵效果；省电和性能策略应保持同一布局。
- 静止时不持续跑光泽或呼吸动画。测量 60Hz/120Hz 下 P95 帧时间、掉帧、内存与关闭玻璃的差异后再决定发布。

## 2026-10-12 交互补充

- 同级主标签使用 MainTabTransition 的主题 effects 淡入淡出；子页面继续使用导航的层级过渡。离场标签保留到结束，但不可接收点击或无障碍操作。SaveableStateProvider 绑定实际显示的标签，不能绑定瞬间变化的选中值。
- SettingsSwitchRow 整行是唯一开关语义入口；滑块仅绘制状态，避免一次操作形成两个焦点或重复写入。星期是独立开关，最后一天不得关闭，并给出轻提示。
- 导入成功先保留确认内容、收起来源面板再回到管理；进入教务任务也先收起来源面板。不能提前清空内容造成闪回来源选择。
- 无绑定课表的作息直接保存；有绑定时仍须展示共享影响。删除课表返回原管理上下文，不暗中切换主标签。
- 课程编辑会话使用 Activity ViewModel 保留旋转/窗口变化；表单草稿和滚动仍由原 saveable 状态负责。进程死亡后会话为空时沿用安全退出，不把空表单当作编辑继续保存；这不是完整的进程死亡草稿恢复。


2026-10-12 组件与安全区补充：桌面卡片独立于App内分组卡，四种桌面组件外轮廓统一28dp并保留16dp内容内缩，避免依赖各品牌桌面追加裁圆。四种组件都填满桌面分配的可用区域；2×2表示格数，不要求正方形，不再通过固定边长缩小卡面。圆角底色直接绘制为圆角图形，外层裁切仅为辅助，避免桌面编辑/退场快照暂时失去裁切时露出方底。主页面宽屏Rail容器负责安全区并向后代消费，导航栏自身的inset不能替代内容区的避让。

2026-10-12 平板导航修订：宽屏导航使用左下方的28dp圆角表面，四个Material导航项保留原有选择/无障碍语义，外围与页面背景同色，取消贯穿整屏的异色侧栏。导航区留12dp外边距、短高度可滚动，紧凑窗口继续使用底栏或Dock。


## 键盘与系统提醒边界（2026-10-12）

- 主 Activity 使用 adjustResize，键盘由既有 Compose inset 负责；不得退回 adjustPan 导致整个页面顶入状态栏。编辑场景需核对键盘弹出后的标题与输入框。
- 提醒开关表示应用保存的偏好，不能代替系统通知/渠道/准时提醒权限。提醒页通过公共说明行与系统设置按钮展示受阻原因；勿扰提示只解释影响，不替用户更改系统偏好。
- 定时广播冷启动 Application 时不得取消正在投递的闹钟或重写其代次。今日/明日摘要各自续排；横幅与持续通知分别使用独立 ID。新增提醒选项需验证真实通知载体，不能仅核对预览。

## 品牌展示的例外（用户明确要求，2026-10-13）

关于页品牌卡的目的包括品牌辨识和惊喜感，可以使用更鲜明的品牌青绿专色、立体倾斜、标识视差与触点光泽。这个例外限定在品牌展示，不将同样效果推广到表单、统计和普通按钮。按压/扫光按需发生，无常驻动画，不抢页面滚动；释放、取消、出界与关闭系统动画均需有明确行为。文字仍须清晰，窄屏/大字体按内容增高，宽屏沿用阅读容器限宽。

## 按压与选中轮廓（2026-10-13 缺陷回归）

同一控件的按压、键盘焦点、选中及状态过渡必须共用视觉轮廓和尺寸/内缩。外层胶囊的clip不能代替每个子项自己的形状。背景画成圆角不等于后续反馈也被裁切。允许点击区域大于视觉区域，但反馈不能画满矩形命中区；使用带feedbackShape/feedbackHeight/feedbackTop的noRippleClickable重载。分组整行选中则沿用整行绘制和父卡片裁切，不盲目将所有行改成独立胶囊。

验收不能只截图最终选中态：持续按住首/中/末项、取消、释放和快速切换；覆盖浮动/贴底底栏和侧栏。PressShapeTest覆盖两种底栏首中末项的按压角落像素与取消恢复。


### 叠层反馈与弱化（2026-10-13）

透明点击区只负责命中，按压/焦点反馈由实际可见的卡面或折角承载；同一个轮换操作覆盖多个命中区时，共享反馈源，不能仅高亮被遮住的底层。叠卡灰显不可直接降低整张卡的透明度，避免底层文字透出；采用不透明表面混色及文字弱化。检查按住截图中的实际可见反馈面积，不以少量抗锯齿像素变化代表反馈清晰。
