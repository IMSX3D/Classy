# Classy v0.09

## 本次更新

- **设置更好找**：整理设置与管理入口，外观和小组件可从「我的」直接打开，关于页的文字也更清楚。
- **直接在课表上加课、调课**：点空白格选择节次，长按课程拖动调整时间。保存前可以确认，保存后可以撤销。
- **作息安排更方便**：设置课时、课间和各时段开始时间，自动排好每一节；导入时可核对作息，确认按钮保持可见。
- **课程和小组件更易读**：统一已结束、节假日课程的变淡效果，改进小组件显示与添加入口。
- **导入与提醒改进**：支持恢复登录阶段的导入草稿，改进部分学校导入和课前提醒，修复赛恩斯部分连堂课被拆开的情况。
- **升级后看看新变化**：更新后首次打开会显示简短说明，关闭后同一版本不再重复。以后的每次升级都会继续提供新版本说明。

## 安装

- 大多数 Android 手机请选择 `app-arm64-v8a-release.apk`。
- 较旧的 32 位设备请选择 `app-armeabi-v7a-release.apk`；x86_64 设备请选择对应安装包。
- 使用正式包名 `com.imsx3d.classy`，版本号 `0.09`、versionCode `9`，沿用正式签名。
- v0.0.2 及以后的正式版可以直接覆盖升级。六个独立测试版使用其他包名，需要先导出课表，再导入正式版。

## 验证与范围

自动测试、构建与签名验证结果见本 Release 的 `verification.json`；文件校验值见 `SHA256SUMS.txt`。

本次没有连接 Android 设备，未执行真机手势、升级安装、通知投递或真实教务账号端到端验收；设备测试包已编译。自动作息与拖动相关的新界面部分文案仍以中文为主。景德镇陶瓷大学适配仍暂停，未加入正式支持名单。

赛恩斯修复对重新导入的课表生效；已有课表不会被自动改写。升级前可先导出课表留存。
