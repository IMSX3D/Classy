# Classy v0.1.0

## 本次更新

- **课表和设置更清楚**：精简顶部按钮，低频操作收进“更多”；整理设置、提示和导入步骤，改善编辑与返回时的状态保留。
- **从教务更新课表**：重新获取课程，保留当前作息；更新前查看变化，保护本地修改。
- **自定义课表背景**：选择图片后，可调节浓淡、模糊、色彩及图片位置。
- **改善平板与桌面组件**：调整顶部安全区、侧栏和内容排版，改善组件圆角、尺寸及预览；本周网格组件可跟随课程色条样式。
- **修正加载、导入和提醒问题**：首次加载不再先误显示“没有课表”或错误周次；改进部分学校作息导入、提醒设置及课程编辑的失败处理。
- **增加细节交互**：“我的”三列统计支持点击查看；关于页有可交互的品牌卡，连续点击可发现开发者来信。

## 下载与升级

- 大多数Android手机和平板下载 **app-arm64-v8a-release.apk**。
- 较旧的32位设备使用 **app-armeabi-v7a-release.apk**；x86_64设备使用对应安装包。
- 正式包名 `com.imsx3d.classy`，版本 `0.1.0`，versionCode `10`，沿用正式签名。已有同签名正式版可直接覆盖升级，无需卸载；升级前建议导出课表留存。
- **“Classy 测试版”与正式版是独立应用**，数据不会自动互通。需要迁移时，先从测试版导出，再导入正式版。
- 更新后首次打开会显示本次简短更新说明，关闭后不重复显示。

## 已知限制

- 冷启动等待和部分页面首次进入仍可能卡顿，本次未实现所有页面完全流畅。
- 小组件自动添加、网格占用和通知展示受手机系统影响；部分设备仍需手动添加组件。原子岛实际展示及长期省电、重启后的通知送达尚未完成全面验证。
- 极窄课表或大字号下，长课程名仍可能省略，可点击课程查看完整内容。
- 新规划的进一步柔化配色、课程块文字调整、品牌礼花、学期安排和生产液态玻璃 **不包含在此版本**。

## 验证

本次构建、回归测试、正式签名与升级验证的实际结果见附件 `verification.json`；安装包校验值见 `SHA256SUMS.txt`。现有v0.0.9及更早标签和发布附件保持不变。
