# Classy v0.1.1

## 本次更新

- **看清整个学期**：新增学期安排，用周次分布查看课程跨度，点开日历查看具体上课日期、时间和教室。
- **新手也能轻松上手**：新增可跳过的快速上手与可反复查看的使用指南，通过小示例学习看课表、导入、调课和设置。
- **打开课表更连贯**：改善首次进入时的等待和闪动，减少课程分批出现的情况。
- **课程显示更清楚**：色条恢复简洁的呈现，已结束和节假日课程的灰显更统一；普通周末有课不会仅因周末而灰显。课表与本周小组件可分别选择课名靠上或居中。
- **小组件与更新更方便**：四种小组件名称更简短，可隐藏课表名称；点击关于页的新版本提示，可直接进入下载更新流程。
- **细节更有趣**：品牌卡外观焕新，连续点击会持续喷射礼花。新安装或恢复默认后，课前提醒提前时间为 5 分钟，提醒仍需自行开启。

## 下载与升级

- 大多数手机和平板下载 **app-arm64-v8a-release.apk**；旧的 32 位 ARM 设备选 **app-armeabi-v7a-release.apk**；x86_64 设备选对应包。
- 支持 Android 8.0 及以上。已有同签名正式版可直接覆盖安装，建议先导出课表备份，不要先卸载。
- 测试版与正式版是独立应用，数据不会自动互通；需要时先导出，再导入正式版。
- 应用内“获取更新”会下载并打开系统安装确认，安装需要你确认。正式版的新版本提示使用同一流程。

## 使用提示

- 桌面组件的大小和添加方式由系统桌面共同决定；应用内添加无效时，可长按桌面空白处手动添加。
- 通知受权限、勿扰和省电策略影响，不能保证所有设备后台场景均能送达。通知栏课程卡片不等于已支持各厂商的原子岛。
- 极窄列或大字号下，长课程名仍可能省略，点击课程可查看完整内容。首次加载改善不代表所有设备、所有页面都无等待。
- 液态玻璃不包含在本版；自定义图片背景可在外观设置中调整。

安装包校验值见 Release 附件 `SHA256SUMS.txt`。开发与验证细节见 [发布准备与验证记录](v0.1.1-preparation.md)。
