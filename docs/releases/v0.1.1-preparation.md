## 展示方向

面向想快速了解课表应用的 Android 用户，以真实界面说明“从今天到整个学期，在手机、平板与桌面看清安排”。中文与英文首页同步，下载指向正式 Release。原有两段品牌影片保留展示位置，后续单独替换。

| 内容 | 依据 | 展示收益与边界 |
| --- | --- | --- |
| 周课表、今日、课程编辑 | 当前 Preview 真机页面 | 快速查看时间地点；不承诺所有配置无卡顿 |
| 学期分布与日历 | SemesterScreen | 看清周次与实际日期；不宣称尚未实现的平板双栏 |
| 四种桌面组件 | 实际桌面宿主 | 不打开应用也能看课；手动添加不称自动添加成功 |
| 背景、色条/填充、深浅主题 | 外观设置与实际课表 | 展示可读性和个性化；不称液态玻璃 |
| 新手教学 | GuideScreen | 可重复练习；教学示例不是系统通知/桌面组件实拍 |
| 品牌互动 | 关于页实录 | 展示连击礼花；不改动原有品牌影片 |
| 导入、教务更新、提醒 | 现有实现与验证记录 | 保留作息、查看变化；不公开账号，不宣称已适配原子岛 |

## 素材和设备约束

独立虚构课表，不覆盖用户原表；拍摄前记录原表和可见设置，拍摄后恢复。手机先拍，真实平板随后补拍，不用模拟器冒充平板。屏幕背景仅使用原创或明确授权素材。实际 UI 不在后期重绘；装饰标题位于截图之外。所有截图须与最终发布候选保持一致，修正后重新拍摄受影响画面。

更新文案遵循 [长期发布规范](MAINTAINING.md)，发布前以真实完成状态更新本清单。
