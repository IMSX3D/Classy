## 二、展示内容

- **首页结构**：定位与徽章 → 宣传片（折叠）→ 整周/今天 → 学期 → 桌面组件 → 配色与背景 → 平板 → 日常操作 → 教务兼容 → 上手 → 彩蛋 → 数据与导出 → 构建 → 参与。
- **素材**：`readme/media/v0.1.1/`，共 34 个文件（24 个 PNG、9 个 JPG、1 个 GIF），全部使用同一套虚构课表，截图裁切在 `readme/media/v0.1.1/README.md` 里声明。
- **中英对照**：中文在根目录 `README.md`，英文在 `readme/README.en.md`，逐节对应，英文版相对路径带 `../`。
- **可验证的诚实边界**：联网只用于教务抓取、不中转第三方、组件刷新与省电影响都写在正文，不承诺未测过的能力。

## 六、素材与设备约束（后续版本继续沿用）

- 只用虚构课表；不提交真实课表、数据库、系统通知或含个人信息的桌面截图。
- 真机测试结束后恢复原课表、主题与显示设置。
- 新增或替换素材必须登记到 `readme/media/v0.1.1/SHA256SUMS.json` 并在该目录的说明文件里写清来源与裁切。
- 已知的一次例外：`brand.gif` 于 2026-10-24 再压缩为 640×575、12 fps、64 色，3.4 MB → 1.7 MB，清单中的哈希已同步；原始版本可从提交历史取回。

## 七、下一次发布怎么用这份文件

把第三节的清单整表复制到新版本的准备文档，逐项替换结果与证据；第四节换成新的提交、证书与资产名；第五节只写真实跑过的项目，没跑的就留在"未做"。面向用户的说明另写 `docs/releases/vX.Y.Z.md`，遵守 MAINTAINING 的 3–6 条规则。
