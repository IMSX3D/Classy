## 下载与安装

到 [Releases](https://github.com/IMSX3D/Classy/releases/latest) 下载 APK。Android 8.0 及以上可用：

| 设备 | 安装包 |
| --- | --- |
| 大多数手机和平板 | `app-arm64-v8a-release.apk` |
| 较旧的 32 位 ARM 设备 | `app-armeabi-v7a-release.apk` |
| x86_64 设备 | `app-x86_64-release.apk` |

打开下载的文件，按系统提示允许该安装来源。已有同签名正式版可直接覆盖升级，建议先导出备份，不要先卸载。测试版与正式版是独立应用，课表需要通过导出、导入迁移。

**我的 → 关于 → 获取更新**可检查、下载并打开系统安装确认。顶部的新版本提示使用同一更新流程。自动检查更新只检查，不自动下载或安装；可在关于页关闭。测试包不获取正式包更新。

升级后首次打开显示本次更新说明；关闭后同一版本不再重复。说明保存在安装包内，不依赖网络。新安装会提供可跳过的快速上手。

## 快速上手与重复学习

第一次使用，可以从 **课表管理 → 导入课表/作息表** 开始。以后到 **我的 → 使用指南** 查看八个主题，也可以重新体验快速上手。

![使用指南和互动示例。](media/v0.1.1/guide.jpg)

教学示例不改真实课表或偏好，不发送提醒；“进入实际功能”才会跳转到对应操作页面。

## 看课表与学期安排

- **课表**：点击顶部名称切换课表，点击周次选择要看的周；更多菜单可切换网格/周视图、添加课程、从教务更新、分享和进入学期安排。
- **今日**：集中查看当天课程、时间与地点。
- **学期安排**：先看各门课程的上课周次分布，再点开月历，选择日期查看当天时间、教室和教师。
- **灰显**：表示已结束或符合节假日淡化条件；多个条件只应用一次淡化。普通周末不因“是周末”而淡化，灰显本身不取消课程或通知。临时停课与补课以学校安排为准。

![学期总览与日期详情。](media/v0.1.1/semester.jpg)

在 **我的 → 设置 → 课表显示** 中调整课程名称位置、补充信息、网格大小、可见星期及节假日设置。隐藏星期不会删除课程。

## 主题与配色

入口：**我的 → 外观与主题**。

| 选项 | 用途 |
| --- | --- |
| 色条 / 彩色填充 | 选择简洁色标或完整课程底色 |
| 统一底色 | 使用统一课程底色，单独指定的课程色仍保留 |
| 主题色 | Android 12+ 可跟随系统壁纸，也可用内置预设或自建主题 |
| 深浅色 | 跟随系统、浅色、深色 |
| 底栏 | 贴底或悬浮；宽屏按可用空间使用侧边导航 |

![深浅色与课程配色。](media/v0.1.1/appearance.jpg)

默认配置采用浅色、系统配色、彩色填充、悬浮底栏；课表和本周组件的课程名默认居中。已有保存设置不会因升级强制覆盖。恢复默认设置会恢复项目当前默认值，不会把其他人的课程或账号导入设备。

## 自定义背景

在 **外观与主题 → 课表背景 → 选择图片** 中选取不超过 20 MB 的图片。展开“调整背景”可以设置：

- 背景浓淡：控制图片的存在感；文字不清楚时适当调低。
- 模糊程度：减少复杂细节的干扰。
- 色彩浓度：让色彩更柔和或保留原色。
- 左右、上下位置：调整铺满屏幕后保留的部分；没有裁切的方向不会产生位移。

拖动时预览，松手保存。可以恢复默认效果或移除图片。预览与实际课表的裁切随屏幕比例变化。

![实际应用的自定义背景。](media/v0.1.1/background.jpg)

## 桌面小组件

四种小组件按 **今日·小 → 今日 → 两日 → 本周** 排列。到 **我的 → 小组件** 查看已放置实例、指定课表及调整共用显示设置。

![四种小组件的真实桌面效果。](media/v0.1.1/widgets.jpg)

- 可隐藏课表名称，显示更简洁。
- 本周网格跟随课程色条/填充样式，课程名顶部或居中可以独立设置。
- 列表与网格可滚动；当前可见内容取决于宿主尺寸、字号与课程数量。
- 添加请求由系统桌面处理。如果应用内添加没有成功，请长按桌面空白处，从“小组件”中选择 Classy，再拖到桌面。
- 不同桌面的网格比例不同，“2×2”不保证物理宽高相等。拖动组件边缘调整大小时，以实际桌面允许的格数为准。

## 导入与导出

入口：**课表管理 → 导入课表/作息表**。导入先预览、再确认；有现有课表时注意选择新建或追加，核对名称、学期开始日期及作息时间。

| 来源 | 方式 |
| --- | --- |
| 教务系统 | 选择学校或输入支持的教务地址，登录后在设备上解析 |
| 文本 | 粘贴 Classy、WakeUp 分享文本、ICS、CSV 等支持的内容 |
| 文件 | 选择 `.txt`、`.json`、`.ics`、`.csv`、`.html` 等支持的课表文件 |

并非任意网页、JSON 或自然语言都能识别；实际兼容取决于格式与学校系统。Classy 原生格式使用 `#classy-v1`，也兼容上游 `#sleepy-v1`。

已有教务课表可以通过 **课表管理 → 从教务更新** 或课表更多菜单重新获取安排。更新前核对差异；刷新保留现有作息，并处理与本地修改的冲突。没有来源关联时需要先选择和确认来源。

导出入口为 **课表管理 → 导出课表/作息表**。按用途选择原生格式、WakeUp JSON、ICS 或文本等；以当前导出页面实际可选格式为准。换设备前建议保留一份原生格式备份。

## 课程提醒

入口：**我的 → 提醒**。开启需要的提醒类型，核对课前提前时间与每日摘要时间，并按页面提示授予系统权限。

新安装或恢复默认后，课前提前时间为 **5 分钟**，提醒总开关默认关闭；修改提前时间并不等于已启用通知。声音、横幅和持续课程卡片仍受到设备系统、通知渠道、勿扰与省电策略影响。通知栏课程卡片不等于已支持所有厂商的“原子岛”。

## 关于页的小惊喜

品牌卡支持按压倾斜和连续点击礼花。持续点击会追加礼花，停手后自然结束；可以探索隐藏的开发者来信。关闭系统动画时以静态反馈为主。

## 从源码构建

前置：JDK 17+、Android SDK Platform 37 与构建工具。本项目本地验证使用 JDK 21。

```bash
git clone https://github.com/IMSX3D/Classy.git
cd Classy
./gradlew :app:testDebugUnitTest :app:assembleDebug
adb install app/build/outputs/apk/debug/app-arm64-v8a-debug.apk

# 使用发布优化的独立测试包
./gradlew :app:assemblePreview

# 正式包，需要配置正式签名
./gradlew :app:assembleRelease
```

Windows 使用 `gradlew.bat`。设置 `JAVA_HOME`、`ANDROID_HOME`，或在忽略提交的 `local.properties` 中设置 `sdk.dir`。首次构建需要下载依赖。

Debug 与 Preview 使用测试应用身份，Preview 保留发布优化；正式包使用独立正式身份。**正式发布任务要求配置签名，不会回退到 debug 签名。** 密钥库及口令不得提交；签名配置键和校验逻辑见 `app/build.gradle.kts`。自己构建的不同签名包不能直接覆盖官方包。

接手开发请读 [贡献指南](../CONTRIBUTING.md)、[接手指南](../docs/engineering/HANDOFF.md) 和 [发布维护规范](../docs/releases/MAINTAINING.md)。复杂实现与验证证据留在开发文档，用户更新说明只讲通俗的体验变化。
